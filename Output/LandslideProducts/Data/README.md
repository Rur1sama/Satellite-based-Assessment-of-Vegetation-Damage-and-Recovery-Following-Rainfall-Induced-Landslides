# Data package contents

The GeoPackage inventory and annual probability rasters in this folder are the final landslide-mapping products staged for release. See the parent `README.md` for scope, interpretation and release checks. The inventory represents nominal occurrence years 2019–2025 from seven annual image pairs spanning 2018–2019 through 2024–2025. The associated Zenodo record is available at [DOI: 10.5281/zenodo.23447197](https://doi.org/10.5281/zenodo.23447197); consult its file list to confirm which products are included.
