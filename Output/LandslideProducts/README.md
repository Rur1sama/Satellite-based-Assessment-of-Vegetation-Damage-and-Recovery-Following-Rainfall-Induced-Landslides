# Landslide products

`Data/` contains the current local release-staging products:

- `Data/landslide_event_inventory.gpkg`: mapped landslide-patch inventory for image pairs 2018–2019 to 2024–2025 (4,429 mapped patches; nominal occurrence years 2019–2025).
- `Data/annual_probability_maps/landslide_probability_18_19.tif` through `landslide_probability_24_25.tif`: seven equal-weight ensemble probability rasters.

The inventory was derived using a probability threshold of 0.8, eight-neighbour connectivity and a minimum patch area of 100 m². These are mapped products, not a field-verified census. The associated code-and-data release is archived on Zenodo ([DOI: 10.5281/zenodo.23447197](https://doi.org/10.5281/zenodo.23447197)); consult the record's file list for the authoritative release contents.
